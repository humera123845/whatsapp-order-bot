# WhatsApp Order Confirmation Bot 🤖

## What This Does
Automatically sends WhatsApp messages to customers
when they place an order on a website.

## How It Works
1. Customer places order on website
2. Website sends data to webhook URL
3. Customer receives WhatsApp confirmation instantly

## Tech Used
- Python
- Flask
- Twilio WhatsApp API
- Deployed on Replit
